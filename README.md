# Sistema de Cadastro de Usuários + Autenticação

API REST para cadastro e autenticação de usuários usando Spring Boot + JWT.

## Tecnologias
- Java 21
- Spring Boot 4.x
- Spring Security
- Spring Data JPA
- JWT (jjwt)
- Banco de dados (PostgreSQL)
- Lombok
- Flyway
- Validation
- MapStruct
- Swagger/OpenAPI

## Funcionalidades
- Cadastro de usuários
- Login com geração de token JWT
- Senha criptografada com BCrypt
- Controle de acesso por roles (USER e ADMIN)
- Proteção de rotas
- Validação de dados
- Tratamento global de exceções
